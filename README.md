# Local Runner Extension

1. افتح `chrome://extensions`.
2. فعّل Developer mode.
3. اختر Load unpacked.
4. اختَر مجلد `chrome-extension`.
5. افتح منصة التدريب وسجّل الدخول بنفسك.
6. افتح أي درس واضغط على أيقونة الإضافة ثم «تشغيل تلقائي».

الإضافة تعمل داخل تبويب المنصة الحالي ولا تنقل كلمات المرور إلى خادم خارجي. هي نسخة اختبارية عامة تعتمد على الأزرار والعناصر الظاهرة؛ إذا كانت منصتك تستخدم selectors مختلفة، أضف `data-testid` أو selectors ثابتة لتحسين الدقة. لا تتجاوز CAPTCHA أو الحماية.
